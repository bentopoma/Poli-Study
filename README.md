# PoliStudy

Plataforma pessoal de organização de estudos desenvolvida
para o Processo Seletivo 2026.2 do Poli AI Club.

## Objetivo

A aplicação busca ajudar estudantes a organizar matérias,
tarefas e provas, auxiliando na definição das prioridades
de estudo.

## Tecnologias utilizadas

- Python
- Streamlit

## Como executar

As instruções completas de instalação serão adicionadas
durante o desenvolvimento.
