# PoliStudy

Plataforma pessoal de organização de estudos desenvolvida para
o Processo Seletivo 2026.2 do Poli AI Club.

## Sobre o projeto

O PoliStudy busca auxiliar estudantes na organização de suas
matérias, atividades e prioridades de estudo.

Atualmente, a plataforma permite cadastrar matérias com sua
dificuldade e meta semanal de estudos. Os dados são armazenados
localmente utilizando JSON.

## Tecnologias

- Python
- Streamlit
- JSON
- Git e GitHub
- Google Antigravity como ferramenta de apoio ao desenvolvimento

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Crie um ambiente virtual:

   python -m venv .venv

4. Ative o ambiente virtual.
5. Instale as dependências:

   pip install -r requirements.txt

6. Execute:

   python -m streamlit run app.py

A aplicação será aberta localmente no navegador.
